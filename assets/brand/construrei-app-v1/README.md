# CONSTRU-REI APP — Kit Mestre de Marca V1

Fonte visual canônica do ecossistema CONSTRU-REI.

## Uso
- `logo-horizontal.webp`: cabeçalhos, relatórios e superfícies horizontais.
- `emblema.webp`: avatar institucional / marca compacta.
- `app-icon-192.png` e `app-icon-512.png`: PWA / aplicativo.
- `apple-touch-icon.png`: iOS.
- `favicon-16.png` e `favicon-32.png`: navegador.
- `banner-central.webp`: hero da Central Operacional.
- `banner-gestor.webp`: hero do Gestor do Projeto.

## Regra canônica
Produtos oficiais devem referenciar estes assets; não duplicar logos por produto e não misturar avatar humano com avatar do sistema.
